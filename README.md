# Rodinné městečko

Klidná hra na život s rodinkou: městečko s obchody, hernou, divadlem a koncerty, výlety autem do zoo, k moři a do lesa a herní telefon.

Hra pro dva: jedna hráčka klikne na **Založit společnou hru** a dostane šestimístný kód, druhá ho zadá v části **Hrát s kamarádkou**.

Propojení zajišťuje knihovna [PeerJS](https://peerjs.com) (MIT licence).
